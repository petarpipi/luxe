# LUXE — Furniture Studio Website Concept

## Short Upwork portfolio description

LUXE is a self-initiated website for a fictional European furniture studio. I set the art direction, wrote the copy, and designed and built a fast, accessible single-page experience: a split editorial hero, a filterable collection with product dialogs, a signature-piece selector, a materials story and a swipeable photo journal. The page is prerendered for an instant first paint, uses hand-written CSS with design tokens and restrained motion that respects reduced-motion settings, and is covered by component, browser and automated accessibility tests at six screen widths.

## Role and scope

Art direction and photo curation, copywriting, interface and responsive design, frontend development, motion, accessibility, performance, testing and documentation.

## Technology list

React · TypeScript · Vite · server-side prerender · CSS design tokens · Motion for React · Lucide · Vitest · Testing Library · Playwright · axe-core

## Selected features to highlight

- One coherent photographic direction: warm daylight, oak, travertine, linen and bouclé.
- Prerendered hero with a preloaded image: content and photograph are visible before JavaScript runs.
- Product dialogs that hand off to a pre-filled consultation form.
- Keyboard-complete tabs, dialogs and lightbox, plus swipe on touch screens.
- Readable typography on phones (nothing below 12 px) and no horizontal overflow from 375 to 1920 px.
